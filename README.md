# 绝地潜兵 2 · 武器击杀阈值与拆毁值计算器

一个纯前端、零依赖的单文件工具，回答两类问题：

- **打几发 / 打多久**能打死某只敌人的某个部位（BTK / TTK）
- **多远之内**能用爆炸拆掉某座建筑（拆毁值）

> 版本 **v0.14** ｜ 149 条武器/战备 × 118 只敌人 × 692 个部位 ｜ 32 个建筑结构 × 44 条爆炸来源

---

下载 `index.html`，用 Chrome / Edge / Safari 直接打开即可，不联网、不安装。

## 两个页签

### BTK 计算 —— 打几发能打死

面板只告诉你「伤害 90」，但打 110 血的头要两发、打 250 血的头要三发。**决定生死的是阈值，不是数字。**

- **BTK 随距离变化**：不是单一数值，是「几米内两发、几米外三发」的阶梯，附曲线与突变点表
- **TTK**：`(BTK − 1) ÷ (RPM ÷ 60)`，不含换弹、瞄准与反应时间
- **五类伤害**：直击 / 爆炸 / 破片 / 多弹丸 / DoT
- **部位机制**：致死与非致死分开算；有流血值的部位给「打残」和「彻底打死」双读数
- **卡阈值警告**：差一点点就能少打一发时提示，并支持双向扫描
  - 这把枪在哪些敌人身上卡
  - 这个部位被哪些武器卡
- **DoT**：燃烧 / 重度燃烧 / 毒气 / 铝热，输出「触发次数 + 累计秒数」，并乘敌人元素倍率
- **自定义输入**：没收录的武器或部位可自行填数，自动标注「（已修改）」
- **导出图片**：一键生成可分享的 PNG 卡片

### 拆毁值计算 —— 多远之内能拆掉

拆毁值与伤害是**两套独立系统**：APW-1 穿甲很高但拆毁只有 20，AC-8 拆毁只有 30。

- **32 个结构**，按阵营分组，标注拆毁阈值与是否需要爆炸（BaDR）
- **44 条爆炸来源**，分 7 组：飞鹰 / 轨道 / 投掷物 / 地雷与哨戒 / 武器与支援 / 超级地球大炮 / 战略级
- **临界距离**：算出「多少米以内还能拆」，附距离色带与衰减曲线说明
- **三种「拆不掉」严格区分**：
  - 拆毁值不足**但有血量** → 提示可清空血量，并给一键跳到 BTK 页的按钮
  - **BaDR 拦截** → 只有爆炸伤害有效，子弹与电弧无效
  - **没有血量** → 真正无法摧毁

## 计算口径

**BTK 侧**
- 只在**最后一步**取整，中间全程浮点
- 甲弹：`AP > AV` 100%，`AP = AV` 65%，`AP < AV` 归零
- 耐久混算：`标准 × (1 − 耐久) + 耐久伤 × 耐久`
- 距离衰减：`α = −4.71e−4 · Cd · D² / m`，`v = v₀e^(αs)`，`rd = 0.75rv² + 0.25`
- 爆炸：简化模型，**内圈全额**，爆抗 100% 转主体
- 传导：`部位伤害 × 传导率`，受部位最大血量封顶
- DoT：只作用于主体，独立穿甲；最后一次触发按剩余血量折算部分时间

**拆毁侧**
- 内圈 `d ≤ r₁`：面板拆毁力全额
- 内外圈之间：普通爆炸 `df × (1 − √x)`，巨型爆炸 `df × (1 − x²)`，其中 `x = (d − r₁)/(r₂ − r₁)`
- 外圈之外：归零
- 结果**截尾取整**；拆毁值与爆炸伤害共用同一条曲线
- 巨型爆炸仅：飞鹰 500KG（主爆）与 df 60 的地狱火级

**不做的**：射流武器逐帧模型、穿透减速、过穿、爆炸外圈衰减、护盾消耗过程。

> 模拟计算数据仅供参考，具体以最新版本游戏内实战为准。

## 目录结构

```
index.html              单文件成品（GitHub Pages 入口）
src/
  index.html            开发源
  engine.js             纯函数引擎（UMD，Node 与浏览器通用）
  build.js              把 data/*.json 内联打包成单文件
  engine.test.js        55 项回归断言
  data/
    weapons.json        149 条武器/战备
    enemies.json        118 只敌人 / 692 部位
sdk/                    机器人 SDK（含拆毁值模块、demo 与 selftest）
demo.js  selftest.js  README.md
```

## 重新构建

```bash
node src/build.js        # 生成单文件 HTML
node src/engine.test.js  # 55 项断言
node sdk/selftest.js     # 全量 10 万+ 组合扫描
```

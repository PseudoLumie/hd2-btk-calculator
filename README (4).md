# 绝地潜兵 2 · 武器击杀阈值与 BTK 计算器

算「**打几发、打多久**能打死某只敌人的某个部位」，而不是给一个平均值。

> 版本 **v0.12.4** ｜ 147 条武器/战备 × 118 只敌人 × 674 个部位

## 直接使用

下载根目录的 **`绝地潜兵2_武器击杀阈值与BTK计算器.html`**，用 Chrome / Edge / Safari 打开即可。

单文件、零依赖、不联网。**不要用聊天软件的「文件预览」打开**——那类预览器通常不执行 JavaScript，会看到「页面没能启动」。

## 功能

- **BTK**：击杀所需击发次数；随距离变化，展示为阶梯而非单一数值
- **TTK**：按射速折算的击杀耗时，`(BTK − 1) ÷ (RPM ÷ 60)`
- **伤害构成**：直击 + 爆炸 + 破片 + 多弹丸，可勾选爆炸波及部位、拖动破片命中数
- **异常伤害**：DoT（燃烧/重度燃烧/毒气/铝热）按「触发次数 + 累计秒数」计算
- **部位机制**：致死/非致死、打残与彻底打死双读数、传导率与传导上限、护盾独立单位
- **卡阈值**：差一点点就能少打一发时提示；支持「这把枪卡哪些敌人」与「这个部位被哪些武器卡」双向扫描
- **自定义输入**：没收录的武器或部位可自行填数（标注为「已修改」）
- **导出图片**：一键生成可分享的 PNG 卡片
- **搜索框**：武器与敌人都支持输入即筛

## 计算口径

- 取整**只在最后一步**发生
- 甲弹：`AP > AV` 100%，`AP = AV` 65%，`AP < AV` 归零
- 耐久混算：`标准 × (1 − 耐久) + 耐久伤 × 耐久`
- 距离衰减：`α = −4.71e−4 · Cd · D² / m`，`v = v₀e^(αs)`，`rd = 0.75rv² + 0.25`
- 爆炸：**简化模型**，内圈全额，爆抗 100% 转主体
- 传导：`部位伤害 × 传导率`，受部位最大血量封顶
- DoT：只作用于主体，独立穿甲，最后一次触发按剩余血量折算部分时间

**不做的**：射流武器的逐帧模型、穿透减速、过穿、爆炸外圈衰减。

> 模拟计算数据仅供参考，具体以最新版本游戏内实战为准。

## 目录结构

```
绝地潜兵2_武器击杀阈值与BTK计算器.html   ← 单文件成品
src/
  index.html      开发源（引用 data.js / engine.js）
  engine.js       纯函数引擎（UMD，Node 与浏览器通用）
  build.js        把 data/*.json 内联打包成单文件
  engine.test.js  55 项回归断言
  data/
    weapons.json  147 条武器/战备
    enemies.json  118 只敌人 / 674 部位
sdk/              给 QQ 机器人 / 后端用的引擎包（含 demo 与 selftest）
docs/             开发笔记与数据审阅
```

## 重新构建

```bash
node src/build.js        # → 生成单文件 HTML
node src/engine.test.js  # → 55 项断言
node sdk/selftest.js     # → 全量 94k+ 组合扫描
```

绝地潜兵 2 · 武器击杀阈值与BTK计算器v0.14

发数不是标量，是距离的阶梯函数。这里算的是「几米内几发、几米外几发」，而不是一个平均值。 要打几发才能打死（BTK = Bullets To Kill）、要打多久（TTK = Time To Kill，按射速折算）。V0.14 包括原版绝大部分潜兵装备和武器，DoT 伤害作为武器条目独立计算，不含射流武器；计算时不考虑过穿和穿透减速。取整只发生在最后一步。模拟计算数据仅供参考，具体以最新版本游戏内实战为准。

公式已验证

  • 距离衰减：AMW-20 补丁说明 200 m「≈92% / 改前≈52%」双点命中
  • 耐久混算：wiki 原文例 BR-14 → 73
  • 传导上限：霸王虫腹板 50,000 等价生命 ×10% = 5,000
  • wiki 战术信息「一记爆头消灭蹂躏者」→ R-63 / P-113 均为 1 发 ✓
  • 甲弹阈值：AP>AV 100% / AP=AV 65% / AP<AV 0

含推演假设

  • 多弹丸按全部命中同一部位合计（霰弹枪、MGX-42）
  • 致死部位：清空部位血量即致死（立即死，或进入流血）；非致死部位只能经传导打死主体，两条路取发数少的
  • 流血时间不计入发数：发数只算到「触发致死」为止
  • hp=null 的部位：与主体共用生命池
  • 不打到穿甲阈值时 BTK 记为 ∞（跳弹）

数据缺失 / 未建模

  • 流血只折算成「秒」，不计入发数：发数算到触发致死为止，敌人流血期间仍在行动
  • 非致死部位被摧毁是否会额外触发主体流血（如强袭虫躯干护甲：表格 fatal=No，正文说会流血）未见规则，v1 依表格
  • 部位被打爆后不再传导：非致死部位若在自身存活期内传不够主体血量，就只报「摧毁它需要几发」
  • 护盾、爆炸、燃烧/毒气 DoT、穿透减速
  • 命中角度按「整体命中」处理，不做弹着点分布

选择爆炸

拆毁值与爆炸伤害共用同一衰减曲线：内圈全额，内外圈之间普通爆炸 ×(1−√x)、巨型爆炸 ×(1−x²)，外圈归零，结果截尾取整。
